# Changelog

## Android 0.1.1 / Flipper 0.0.10

- Added an in-app language selector with 25 Android interface languages.
- Added a Flipper application section that downloads the existing Flipper Messenger 0.0.10 `.fap` to the phone.
- Added copyable Command Prompt and PowerShell installation commands for Windows.
- Added explicit USB-transfer instructions and an Android share-file workflow for moving the `.fap` to a computer.
- Kept the Flipper application and protocol at version 0.0.10 with no Flipper code changes.
