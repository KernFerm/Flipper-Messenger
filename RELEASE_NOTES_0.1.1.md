# Flipper Messenger Android 0.1.1 / Flipper 0.0.10

This release updates only the Android companion. The Flipper Zero application remains version 0.0.10.

## New in Android 0.1.1

- Choose from 25 Android interface languages inside the app.
- Download the official Flipper Messenger 0.0.10 `.fap` directly to the phone.
- View and copy one-line Command Prompt or PowerShell installation commands.
- Move the downloaded `.fap` to a computer using detailed USB steps or Android's Share menu.
- Install as an update over Android 0.0.45 using the same release signing key.

The `.fap` file does not run on Android. Transfer it to a Windows computer, connect the Flipper Zero by USB, close qFlipper, and use the command shown in the Android app.
